# Changelog

## 0.1.0 — Initial public release

- Annual effective rate calculation for a single repayment or dated cash flows.
- Fixed 365/366 and calendar ACT/ACT bases, with the legacy LEGAL alias documented.

- Optional Windows typing help through Excel-DNA IntelliSense 1.9.0.
- Fifty recorded desktop Excel checks, source-to-workbook validation, and sanitized workbook metadata.
- MIT licensing, dependency notices, CI checks, and deterministic release packaging.
